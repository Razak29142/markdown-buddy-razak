## Question 1: How did AI help you create and improve your Markdown documentation?

ChatGPT helped me understand how to organize a professional README file for an R project. It suggested sections such as Overview, Installation, Example Usage, and License. It also helped me structure the R Markdown document using headings, explanations, and code blocks. I learned that AI can save time when preparing documentation, but the information still needs to be reviewed carefully. The most useful part was having a clear structure that made the project easier to understand.

## Question 2: What are the benefits and limitations of using AI for project documentation?

One major benefit of AI is that it can quickly suggest documentation layouts and improve the clarity of explanations. It is especially helpful for beginners who are learning Markdown syntax and R project organization. However, AI can sometimes provide incorrect code, missing information, or explanations that do not match the actual project. Therefore, I should not depend completely on AI-generated content. I need to review the documentation, check the code, and make sure everything accurately describes my project.

## Question 3: Why is validation and ethical AI use important when creating technical documentation?

Validation is important because technical documentation should be accurate and easy for other people to follow. A README may look professional but still contain incorrect instructions or code examples. I can check Markdown formatting using GitHub's preview and test R Markdown using RStudio or Posit Cloud. Ethical AI use also means explaining which AI tool was used, recording the prompts, protecting private information, and taking responsibility for the final work. This assignment helped me understand why AI should support my learning rather than replace my own judgment.
